# Screenshots

Store PulseStock screenshots in this directory so GitHub can display them in
the main project README.

Recommended filenames:

- `Dashboard.png`
- `Results.png`
- `sentiment-filter.png`

Embed a screenshot from the project README with:

```markdown
![PulseStock dashboard](fotos/Dashboard.png)
```

Use PNG or WebP images and avoid including API keys, terminal output containing
secrets, or other private information in screenshots.
