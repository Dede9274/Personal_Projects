One-time setup
  1. Install dependencies: pip install flask requests
  2. Set FINNHUB_API_KEY and ANTHROPIC_API_KEY in the server environment.
  3. Run python3 finnhub_proxy.py and open http://localhost:5050.

Both API keys and the sentiment prompt stay on the Flask server. The browser only calls local API endpoints.
